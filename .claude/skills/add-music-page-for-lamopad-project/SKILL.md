# Как добавить страницу трека на lamopad.ru

Эталонная реализация: /tracks/sun-coming-glasses/ (отражает предпочтения владельца).
Ещё пример: /tracks/milky-way/.

## Суть

- Страница посвящена ПЕСНЕ: дизайн, образы и интерактив должны вырастать
  из текста, вайба и обложки конкретного трека. Сначала проанализируй текст
  и обложку — фишки и находки строй на их особенностях.
- Каждой странице — УНИКАЛЬНЫЙ интерактивный слой на основе обложки
  (milky-way: космос-канвас, ловля падающих звёзд → загадать желание;
  sun-coming-glasses: закатный градиент, дышащее солнце, шагающие очки,
  кликабельные пальмы, с которых падают ламы 🦙). Уважать
  prefers-reduced-motion.
- ТЕКСТ ТРЕКА НЕ МЕНЯТЬ — он авторский. Максимум — форматирование.
  Нашёл ошибку правописания — спроси, НЕ исправляй сам.

## Файлы и структура

- Папка /tracks/<slug>/ — slug идёт в URL: латиница, нижний регистр, дефисы.
- Исходники: текст + аккорды + ссылки на площадки — tracks/<slug>/<slug>-text.txt
  (аккорды в русской нотации: H = B); mp3 — tracks/<slug>.mp3;
  обложка — tracks/<slug>-cover.jpg|png.
- Один самодостаточный index.html: vanilla HTML/CSS/JS, без сборки.
- Favicon — обложка: <link rel="icon" href="/tracks/<slug>-cover.jpg">
  (или отдельная иконка <slug>-icon, если есть).
- Опциональная фишка (как в milky-way): обложка как CSS-курсор страницы.

## Анатомия страницы (сверху вниз)

- Хлебные крошки — нормальные кликабельные ссылки:
  Ламопад (/) → Треки (/tracks/) → <Название трека>.
- Шапка: обложка (84–132px) + h1 + «ЛАМОПАД» + 3 mood-чипа.
- Короткое описание курсивом в рамке. БЕЗ секции «О песне» и без
  отдельных секций-тизеров с кнопками — интерактив живёт в самой сцене.
- Кастомный аудио-плеер (кнопка play + прогресс + время).
- Кнопка «Скачать MP3», разделитель «—или—», ссылки на площадки:
  Яндекс Музыка, VK Музыка, Spotify, Apple Music, YouTube (иконки —
  simpleicons CDN, Яндекс — wikimedia); Звук, КИОН, Wink — текстом.
- Табы «Текст» / «Аккорды» (.chord-line + абсолютные .chord-спаны).
- Оформление самого текста трека — БЕЗ мудрёного разнообразия: текст
  ± однородный. Максимум — СЛЕГКА различить куплет и припев по дизайну.
- После текста, перед футером: story-ссылки на другие треки (статично,
  выбрать из /tracks/) + ссылка на официальный клип, если есть.
- Футер большой и хорошо читаемый: «Треки Ламопад» → /tracks/.
  В самом-самом конце: © Ламопад — все права защищены.

## Вёрстка и мобильность

- Mobile-friendly ОБЯЗАТЕЛЬНО: текст хорошо читается на телефонах,
  планшетах, ноутбуках.
- Контентная панель: max-width 860px; фон достаточно плотный
  (rgba + backdrop blur), чтобы текст читался поверх сцены.
- Шрифты: Nunito (текст) + Unbounded 700/900 (заголовки), Google Fonts.
- Flex-детям min-width: 0; длинным русским словам — &shy;-переносы.
- Ловушка тестирования: headless Chrome не сужает окно ниже ~500px,
  поэтому «переполнение» на скриншотах 390px часто фантомное.

## SEO

- title «<Название> — текст песни и аккорды | Ламопад», meta description,
  keywords, OG + twitter cards, canonical https://lamopad.ru/tracks/<slug>/,
  JSON-LD MusicRecording, itemprop lyrics.
- Аналитика — сниппет GoatCounter в <head> (единый для всего сайта):
  <script data-goatcounter="https://lamopad.goatcounter.com/count"
          async src="//gc.zgo.at/count.js"></script>

## После создания

- Добавить страницу в sitemap.xml с сегодняшней датой.
- Добавить трек в /tracks/index.html: строка в списке (название + ссылки
  «текст» / «mp3», «караоке» если есть) и трек в плейлист APlayer.

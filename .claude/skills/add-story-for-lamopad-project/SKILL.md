# Как добавить страницу рассказа на lamopad.ru

Эталонная реализация: /stories/dva-bileta/ («Два билета»).
Ещё пример: /stories/real/ («Кому верить»).

## Суть

- Страница — авторский короткий рассказ. Главное — ЧИТАЕМОСТЬ текста.
- Дизайн бери из существующих рассказов (если юзер явно не просит другой).
  Мини-фишки — из особенностей текста: сначала проанализируй рассказ,
  потом придумай кастомизацию под него (пример: у «Двух билетов» реплики
  оформлены классом .dialogue, финальная фраза — .final).
- ТЕКСТ РАССКАЗА НЕ МЕНЯТЬ — он авторский. Максимум — форматирование.
  Нашёл ошибку правописания — спроси, НЕ исправляй сам.

## Файлы и структура

- Папка /stories/<slug>/ — slug идёт в URL: латиница, нижний регистр, дефисы.
- Один самодостаточный index.html: vanilla HTML/CSS/JS, без сборки.
- Курсор страницы: cursor: url('/img/lamopad_cursor_48px.png'), auto.
- Favicon: /img/slon_32px.jpg.

## Анатомия страницы (сверху вниз)

- Хлебные крошки — нормальные кликабельные ссылки:
  Ламопад (/) → Рассказы (/stories/) → <Название рассказа>.
- Заголовок + байлайн «рассказ · Ламопад».
- Текст рассказа.
- Если рассказ связан с треком — aside-блок (.track-cta): личная заметка
  о связи + ссылка на трек (у «Двух билетов» — «Млечный Путь →»).
- Блок «Ещё от Ламопада»: ссылка «Треки Ламопад →» на /tracks/,
  затем «Другие рассказы» — статичные ссылки на другие рассказы
  (выбрать из /stories/, whom-to-trust не считать — это редирект на real).
- Футер большой и хорошо читаемый.
  В самом-самом конце: © Ламопад — все права защищены.

## Вёрстка и мобильность

- Mobile-friendly ОБЯЗАТЕЛЬНО: текст хорошо читается на телефонах,
  планшетах, ноутбуках. Читаемость важнее фишек.

## SEO

- title «<Название> — Ламопад», meta description,
  canonical https://lamopad.ru/stories/<slug>/,
  OG (og:type article, og:locale ru_RU, og:site_name Ламопад,
  article:author Ламопад) + twitter cards.

## После создания

- Добавить страницу в sitemap.xml с сегодняшней датой.
- Добавить карточку рассказа на /stories/ (index).
- ПЕРЕКРЁСТНЫЕ ССЫЛКИ: в существующие рассказы добавить ссылку на новый
  в блок «Другие рассказы».

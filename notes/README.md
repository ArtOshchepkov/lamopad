# notes/

Мини-блог о путешествиях на сайте Ламопада.

Каждая поездка — отдельная папка:

```
notes/
└── thai/          ← Таиланд 2026
    ├── index.html     страница для публикации
    ├── thai.txt       черновик заметок
    └── *.jpg          фотографии
```

## Как добавить новую запись

1. Создать папку с названием поездки (`notes/bali/`, `notes/georgia/` и т.д.)
2. Положить туда исходные заметки в `.txt` и фотографии
3. Создать `index.html` в том же стиле (тёмная тема, акцент #e8a04a, mobile-first, FAQ, CTA на band.link/lamopad)

# Озвучка «Солнценаступательных очков»

Полный список событий и штук, которым нужен звук.
✅ — уже озвучено · ⭐ — из заметок владельца («надо озвучит»)

## Платформы и отскоки

- [ ] Обычный отскок от облака — мягкий «пум», основной звук игры (слышен чаще всего, не должен надоедать)
- [ ] Стикер «нехай повисит» — отскок + шурх отклеивающейся бумажки
- [ ] Рюкзак-батут — пружинистое «бо-ин-нг»
- [ ] ⭐ Лама-мегабатут — мощный батут + возглас «Там хорошо!» (игрок сильно ускоряется)
- [x] ✅ Пташка — крик чайки (`seagul_ira.mp3`)
- [ ] Стесняшка-закатик — застенчивое хихиканье/«ой», когда краснеет и тает
- [ ] Чемодан проламывается — треск/хруст картона (отскока нет, игрок проваливается)
- [ ] ⭐ Супер Марио-блок — «динь» монетки + превращение в ГРИБКА («игра где ты типа грибок», СТЁПА)

## Опасности и смерти

- [ ] Крокодил съедает — «АМ!»
- [ ] ⭐ Змея съедает — шипение «Ш-ШШ!»
- [ ] ⭐ Молния — треск разряда + раскат грома (бьёт при прыжке на тучу и сама по себе)
- [ ] Телеграф тучи — нарастающее потрескивание 0.8 сек перед самопроизвольным ударом (туча мерцает)
- [ ] Смерть от молнии — «ЖАХ» / электрический хруст (игрок обугливается и падает)
- [ ] ⭐ Падение игрока вниз — протяжное «О-ооооу»

## Пикапы

- [ ] Подбор реактивного ранца
- [ ] ⭐ Полёт на ранце — «ВЖ-Ж-Ж» или голосом «реактиввный ранец» (2.2 сек полёта)
- [ ] Отвал отработавшего ранца (кувыркается вниз)
- [ ] ⭐ Вход в пузырь — булькающее «блюм»
- [ ] ⭐ Пузырь лопается — «ПЫК» (сам, по тапу или от ракеты)

## События мира

- [ ] Пролом офисного потолка — треск плит + «К чёрту потолок!» (первый прыжок вверх)
- [ ] ⭐ Ворчание облака — фразы, когда прыгаешь на одном месте 7+ раз («Ну сколько можно?», «Там хорошо, вообще-то», «Сам, а не само!»)
- [ ] ⭐ Дождевой пояс — луп дождя; идея владельца: «а на райо-о-не идёт до-о-ождь»
- [ ] Падающая лама — кувыркается через экран с криком
- [ ] Самолёт — далёкий гул (типы: cessna / лайнер)
- [ ] Светлячки разлетаются от игрока — рассыпчатый звон

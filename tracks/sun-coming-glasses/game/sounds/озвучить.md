# Озвучка «Солнценаступательных очков»

Игрок прыгает по облачкам. На взаимодействия игрока с миром и экраны нужны звуки.

## Платформы и отскоки

- [ ] Обычный отскок от облака — мягкий «пум», основной звук игры.
- [ ] ⭐ Лама-мегабатут — мощный батут.
- [ ] Чемодан проламывается — треск/хруст картона (отскока нет, игрок проваливается)
- [ ] Пролом офисного потолка — треск/хруст потолочного перекрытия

- [x] ✅ Пташка — крик чайки (`seagul_ira.mp3`)

## Опасности и смерти

- [x] ⭐ Молния — треск разряда + раскат грома (бьёт при прыжке на тучу и сама по себе)
- [x] Телеграф тучи — нарастающее потрескивание 0.8 сек перед самопроизвольным ударом (туча мерцает)
- [x] Смерть от молнии — «ЖАХ» / электрический хруст (игрок обугливается и падает)
- [50] ⭐ Падение игрока вниз — протяжное «О-ооооу»

## Пикапы

- [ ] Подбор реактивного ранца
- [x] ⭐ Полёт на ранце — «ВЖ-Ж-Ж» или голосом «реактиввный ранец» (2.2 сек полёта)
- [ ] Отвал отработавшего ранца (кувыркается вниз)
- [x] Вход в пузырь — булькающее «блюм»
- [x] Пузырь лопается — «ПЫК» (сам, по тапу или от ракеты)

## События мира

- [ ] Пролом офисного потолка — треск плит + «К чёрту потолок!» (первый прыжок вверх)
- [ ] ⭐ Ворчание облака — фразы, когда прыгаешь на одном месте 7+ раз («Ну сколько можно?», «Там хорошо, вообще-то», «Сам, а не само!»)
- [ ] ⭐ Дождевой пояс — луп дождя; идея владельца: «а на райо-о-не идёт до-о-ождь»
- [ ] Падающая лама — кувыркается через экран с криком
- [ ] Самолёт — далёкий гул (типы: cessna / лайнер)
- [ ] Светлячки разлетаются от игрока — рассыпчатый звон

## Вехи и интерфейс

- [x] ✅ Веха 330 м «Эйфелева башня» — круассан («crusassan_gleb.mp3»)
- [ ] Универсальный звук взятия вехи (флажок + золотая плашка)
- [ ] Уникальные вехи — по желанию: Лахта («кукурузина»), Бурдж, Шерегеш, Камю, Роза Пик, Фудзи («конничива»), Белуха, Эльбрус, Эверест, Стратосфера
- [ ] Ачивка (плашка ★ 🏅 ★) — отдельный, торжественнее вехи
- [x] ⭐ «НОВЫЙ РЕКОРД!» — голосом, с фанфарами (салют уже есть)
- [ ] Кнопка «Погнали!» на старте + взлёт-переход
- [ ] Тумблеры/клики UI — короткий тактильный «тык»
